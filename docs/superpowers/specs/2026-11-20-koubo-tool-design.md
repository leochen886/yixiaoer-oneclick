# 剪口播 + 字幕 一键工具 · 设计

日期：2026-11-20

## 意图 / 为什么

替代「扔进剪映 → 智能剪口播 → 加字幕」这套纯手工活：把视频**拖一下**，自动出「剪掉气口（停顿 + 口水词）+ 烧好大字幕」的成片。全程不用大模型、不联网、不云。

## 目标

- 输入：一个 mp4 口播视频。
- 输出：剪掉停顿/口水词、烧好字幕的 mp4（另存一份 .srt 字幕）。
- 交互：拖到图标 / 右键「发送到」，静默跑完弹通知 + 打开输出目录。

## 非目标

- 不用大模型、不联网、不云。
- 不做错别字纠正：字幕 = FunASR 原样输出，可能有少量同音字错。
- 不做倍速、B-roll、配乐。

## 反目标（做成这样就等于失败）

- 不能剪到字——切点必须落在静音区。
- 不能误删实义词——只删停顿和口水词，不删正常内容。

## 方案取舍

- **A（采用）**：复用 `koubo/` 已验证脚本 + 新增「自动删口水词」模块 + 一条编排入口 + 拖拽交互。
- **B（否决）**：从零重写更干净的架构。现有脚本已经跑通过，重写是白干。
- **C（否决）**：只用 `ffmpeg silencedetect` 剪静音。删不掉「嗯/啊/然后/就是」这类口水词，达不到「智能剪口播」效果。

## 设计

### 交互（方案 A + B）

- `剪口播.cmd`（拖拽目标，隐藏窗口）：拿到视频路径 → 调 `python koubo.py <视频>` → 跑完弹通知 + 打开输出目录。
- `shell:sendto` 放同款入口，右键视频 → 发送到 → 「剪口播+字幕」。

### 管道（`koubo.py` 一条脚本串起来）

1. `ffmpeg` 抽 16k 单声道 wav。
2. FunASR 转写（paraformer-zh + fsmn-vad + ct-punc，CPU）→ 文本 + 时间戳。
3. **自动删口水词**（新增核心模块）：
   - 用口水词表（`嗯/啊/呃/哦/然后/就是/那个/这个/就是说/…`，可配置）在转写文本里匹配，把命中字的时段标成「删」；
   - 词与词间隔 > 阈值（默认 0.3s）的停顿也标成「删」。
4. 生成 keep 片段（保留区间的补集 + 边缘 padding）。
5. `snap_segments` 把切点吸附到最近静音窗（保证不剪到字）。
6. `self_check` 自检切点能量，剪到字就警告。
7. `cut_video` ffmpeg trim+concat 裁剪。
8. `build_ass` 用「去口水词后」的文本生成大字幕，`burn_subs` 烧进成片。
9. 通知完成 + 打开输出目录。

### 输出

- `output/<原名>_cut.mp4`（烧字幕成片）
- `output/<原名>_cut.srt`（字幕旁车）
- `output/<原名>_run/`（中间产物 + 日志，便于排查）

### 配置（`koubo-config.json`）

口水词表、最小停顿阈值、边缘 padding、字幕字号/位置、输出目录、是否保留 srt。

### 复用 vs 新增

- **复用**：`transcribe_funasr.py`、`snap_segments.py`、`self_check.py`、`cut_video.py`、`build_ass.py`、`burn_subs.py`。
- **新增**：自动删口水词模块、`koubo.py` 编排入口、拖拽/发送到入口。
- **退役**：手动 `corrected.txt`/`cleaned.txt` 那套（`sentences.py` / `edit_map.py` / `assemble.py` 不再需要）。

## 留给实现者（我的调用，会在计划里定）

- 进度/通知机制的具体实现（PowerShell toast 或弹窗 + 打开输出目录）。
- 单条失败时的容错与日志（ASR 失败、无音频轨、超长视频等）。

## 关键取舍（需你确认）

字幕 = FunASR **原样**文字，**不做错别字纠正**。纠正需要大模型，或你手动改稿——那正是你想甩掉的手工活。代价是字幕偶尔会有同音字错（如「他/它」「在/再」）。这是「不要大模型 + 不要手动」的自然代价。
